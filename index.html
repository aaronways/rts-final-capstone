Configuration under test

  • Button on GPIO 18, internal pull-up, negative-edge interrupt, 200 µs debounce gate.
  • IRAM_ATTR ISR raises a scope pulse on GPIO 19, timestamps entry, and signals two bottom halves.
  • Two bottom-half tasks at priority 12 on Core 1: one binary semaphore, one direct task notification.
  • Four periodic load tasks on Core 1 at the rate-monotonic ladder, priorities 15 / 10 / 5 / 2.
  • Compile-time switches: WITH_LOAD, BREAK_YIELD.

Read the measurement before you interpret it. Both bottom halves subtract from one shared isr_entry_time_us, and whichever task runs second absorbs the first task's UART print inside the measured window. In the idle run the semaphore figure scatters between 915 and 2560 µs while notification holds 20–30 µs; at hit #50 of the loaded run the order flips and notification is the one reading 2246 µs.
